# Worket 桌宠外形探索

日期：2026-09-24。分支：`codex/pet-appearance-exploration`。

问题：现有桌宠较简陋，哪种外形在真实的小尺寸和四向贴边下更有性格，并且能合理接入当前 Electron 产品？

## 客户端接入

2026-09-24 用户要求按当前方案更新并运行。生产渲染已接入 `src/renderer/pet-visual.ts`，使用 `pet-assets/` 中原样复制的 v2 / v3 PNG；状态由 PetView 与沉淀活动驱动。`AppUpdates.state` 经 PetView 传递无更新 / 有更新 / 下载中 / 已就绪，保留点击同意后才下载的流程。工作光色与更新波纹独立。

自由态角色主体仍约 78px；完整 SVG 裁切视窗约 80.23 × 76.89，布局与命中区留 80.25 × 77。贴边窗口保持 32 × 68 / 68 × 32。便利贴的独立按钮覆盖原素材位置，悬停才展开文字；收纳克隆保留独立 SVG 遮罩 ID。两秒轮询不重建相同状态的素材。

`/exploration` 的旧对照已冻结为接入前 `e40e05e` 的 `baseline/` HTML / CSS，避免生产渲染升级后丢失原版参照。以下为原型阶段记录；当前客户端验收见 `docs/acceptance/pet-appearance.md`。

## 原型方向：拟物版，用啾啾的发光色表示状态

用户已否定本轮五种新造型，并要求继续优化此前拟物土豆的贴边与头顶啾啾。默认入口现在是 `refinement.html`；旧五方案只在 `/exploration?variant=A` 保留为历史材料，下面旧推荐不再生效。

用户随后认可整体与啾啾，认为眼神偏眯，要求沿这一版补齐所有状态。新增 v3 睁眼图集，使用内置 `image_gen` 编辑模式。为避免整图生成改变已认可部位，页面只取 v3 眼部的 clipPath 区域叠加到原 v1 / v2 底图，身体、便利贴、小芽、爪尖继续使用原文件。休息不叠加睁眼层。所有源图按原文件复制保存，没有脚本重绘或抠图。此前两轮提示词见 [REFINEMENT-PROMPTS.md](REFINEMENT-PROMPTS.md)，本轮精确提示词见 [EYES-PROMPT.md](EYES-PROMPT.md)。

最新反馈：用户要求将状态圆点换成啾啾，用芽尖的发光色表示状态。当前原型移除圆点与其勾号 / 叹号，小芽在所有状态常驻；复用 v2 有芽姿态，只对芽尖叠加颜色、原材质亮度和柔光，芽颈渐隐回金色。休息熄灯。贴边仍只露窄头部、竖向双眼与扁爪尖，小芽朝桌面内侧，嘴和便利贴收起。此轮没有生成或改写 PNG；既有图集仍不是最终生产分层素材。

### 状态覆盖

| 状态 | 视觉反馈 | 当前业务来源 |
| --- | --- | --- |
| 休息 `sleeping` | 闭眼，金色啾啾熄灯 | 没有正在记录或等待的工作 |
| 记录中 `awake` | 绿光 `#55d59b` 缓慢明暗，身体轻呼吸 | 有工作正在记录 |
| 等待接入 `waiting` | 暖橙光 `#ffae58` 常亮 | 等待会话绑定、等待确认或尚未读取工作包 |
| 携带 `carrying` | 天蓝光 `#76baff`，身体小幅起伏 | PetState 已定义，当前没有业务赋值触发，标为预留 |
| 提醒 `alert` | 珊瑚红 `#ff7969` 提示三次后常亮 | PetState 已定义，当前没有业务赋值触发，标为预留 |
| 沉淀中 `distilling-running` | 淡紫光 `#b294f6` 缓慢明暗，纸片线条依次亮起 | 沉淀任务 PREPARED / SUBMITTED / RUNNING |
| 待审阅 `distilling-ready` | 青白光 `#c1fff1` 提示、轻跳三次后静止 | AWAITING_REVIEW |
| 需处理 `distilling-failed` | 珊瑚红 `#ff7969` 提示、轻摇三次后静止 | FAILED / INTERRUPTED / NEEDS_SELECTION |

依据：`src/ui-contract.ts`、`src/app/app-service.ts` 的 captureStatus / globalPetState、`src/distillation/activity.ts`、`src/renderer/pet.ts` 与 `pet.css`。真实渲染器在存在沉淀活动时覆盖普通 PetState；预览逐项展示最终视觉状态，不另造业务优先级。所有状态主体保持金色，以芽尖光色和克制动作区分，贴边不移动头和爪尖。

更新是独立视觉维度：无更新（无波纹）、有更新（一道细波纹）、接收中（两道波纹依次明暗）、已就绪（两道波纹常显）。波纹使用中性色，不覆盖芽尖的工作状态颜色；无更新也保留小芽。八种状态可与四种更新表现组合，共 32 组；每组都有自由态与上 / 右 / 下 / 左四向。更新表现是设计方案，现有 `AppUpdateManager` 尚未向 PetView 发布这些状态。悬停 / 按住放大自由态可查看抬起与按压反馈，未模拟系统窗口拖动。

### 素材与几何核对

- `assets/clay-poses-v1.png`：来源 `exec-87a02c21-448f-48c5-a54b-b7ac5b4b2aa3.png`；1254 × 1254 RGBA。
- `assets/clay-poses-v2.png`：来源 `exec-f4025b81-7f9e-4be3-8600-6799e28c396f.png`；1254 × 1254 RGBA。
- `assets/clay-poses-awake-v3.png`：来源 `exec-de17b9e1-b8fe-4340-b7bd-dcf2b0a84cd4.png`；1254 × 1254 RGBA，真实 alpha 0–255。仅显示眼部裁切，原主体不替换。当前 `clay-pet.js` 只用自由 / 贴边两组有芽裁切窗，集中眼部、芽尖、遮罩与渐隐方向的坐标。
- 两张均有真实 alpha（0–255）；没有用脚本抠图或补画。alpha > 200 测得 v2 自由有芽区域 `(687,141)-(1178,581)`，贴边普通区域 `(280,734)-(470,1137)`，贴边有芽区域 `(841,734)-(1072,1137)`。
- 自由主体按 `78/490` 缩放；右侧完整裁切窗为 269 × 571 图像像素，按 `32/269` 缩放放入 32 × 68 CSS px 窗口。普通可见轮廓约 22.6 × 47.9px，有芽约 27.5 × 47.9px。其他方向旋转相同的裁切窗口，不另猜位置。
- alpha > 200 的四邻域检查确认两种有芽姿态的芽头、连接处都与头部相连，贴边上下爪尖也与头部相连。浏览器 DOM 核对四向窗口为 32 × 68 / 68 × 32；未执行原生 Electron 拖动或收纳动画验收。
- 状态光使用原图 alpha 遮罩，保留不规则芽头边界。自由芽尖中心 `(939,156)`，遮罩 `(912,136,53,44)`，沿 y=165→179 渐隐；贴边中心 `(857,939)`，遮罩 `(834,918,54,42)`，沿 x=866→886 渐隐。坐标按 alpha 截面核对，发光方向随既有贴边旋转。柔光范围在原裁切窗内，原生窗口尺寸不扩大。
- 尚需正式制作时处理：生成透明边缘的零散低 alpha 像素、姿态间主体一致性、单独小芽 / 五官分层、四向光照。现在的旋转预览也会旋转图像内光照，不能称作四向原生素材完成。

### 预览检查

通过内置浏览器逐项点击八种状态与四种更新选项，核对 32 组、160 个自由 / 四向组合：所有姿态有芽且没有圆点，睡眠不发光也没有睁眼层，其余状态灯颜色正确，所有 SVG ID 唯一，更新波纹数量正确且不改变状态光色，柔光未越出裁切窗，四向窗口尺寸正确且主体无位移动画。读取实际 CSS 确认完成 / 异常光效只有三次；暂停 / 播放及深浅背景均检查。reduced-motion 规则通过代码检查，未切换系统辅助功能设置。

状态灯核对原始记录保存在本机 `output/pet-appearance/bud-glow-checks.json`；此前圆点版记录保留在 `state-checks.json`。本轮只对原型执行 JavaScript 语法、diff 和浏览器检查，不新增单元测试或生产发布门禁。页面及更新动效仍为浏览器模拟，不代表原生状态接口、拖动、命中区域或性能已验收。

## 历史：已被否定的五种扩散方案

| 方案 | 设计变量 | 实现路径 | 相对成本与取舍 |
| --- | --- | --- | --- |
| A 软糖小团 | 轮廓、眼神、柔和高光、减轻投影 | 分层 CSS | 低；品牌延续强，变化较克制 |
| B 豆豆贴纸 | 不对称豆形、描边、手脚 | SVG 轮廓与分层五官 | 低—中；辨识度强，卡通性格明显 |
| C 纸页信使 | 把记录纸页变成角色本身 | SVG 折角纸页 | 中；工作隐喻直接，独立记录入口需要重新设计 |
| D 像素工友 | 像素格、方块五官、逐帧感 | 像素 SVG 或 sprite sheet | 中；风格鲜明，整数倍率与 Retina 需核对 |
| E 奶油陶土 | 体积、短手脚、柔软材质 | 透明素材与局部动效 | 中—高；当前代码只近似材质，正式素材一致性是主要成本 |

以上为首轮基于源码的工程判断，不是实测工期或性能结论。首轮曾推荐 A/B；用户已否定这些新造型，不再继续这一推荐。

## 判断依据与边界

- 当前 `src/renderer/pet.html` / `pet.css` 在 `/baseline` 原样载入 DOM 与样式；只移除生产脚本、调整预览位置并注入模拟状态。没有复制重画当前桌宠，预览也不访问 Worket IPC。
- 当前角色的原生布局为 78 × 70.5 CSS px，其中主体为 78 × 67.5；透明窗口 304 × 271。依据：`src/desktop/pet-layout.ts`、`src/renderer/pet.css`。
- 候选统一在 78 × 70.5 布局下展示，具体轮廓允许改变；四向紧凑窗口为 68 × 32 / 32 × 68。紧凑姿势是候选设计，尚未通过系统窗口命中区和拖动验证。
- 当前状态、更新波纹和背景切换均在内存中模拟；URL 只记录预览选择，不写产品配置。完成与异常的动作次数有限，贴边时只改变芽尖光色，不挪动五官。首轮旧五方案仍保留独立圆点，仅供历史追溯。
- E 使用 CSS 渐变与噪声近似轻拟物材质，不能代表此前生成图已被等比复现。真正拟物方案可用分层透明图片实现，不强制引入实时 3D；贴边、表情与光照的一致性仍需制作验证。
- `assets/previous-material-study.png` 是此前任务 `01a0c7f8-1c71-7283-93f0-d3bdfef96729` 在 2026-09-22 生成的参考原图，按原文件复制，未编辑。来源文件名 `exec-e3f418e9-a3ec-476b-ab0d-460857cc126b.png`。不是当前已安装应用的截图。
- 原型位于打包已排除的 `research/`，只在本分支保留；生产 `src/`、图标和应用包均未更换。选定后再将一种造型接入真实状态、点击/拖动、收纳过渡与应用图标。
