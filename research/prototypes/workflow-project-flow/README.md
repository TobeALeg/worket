# 工作流 Project Flow 方向稿

问题：如何把用户指定的轻卡片、细连线与空间留白，变成能够表达真实运行、成果采用与验收返工的 Worket 工作台？

视觉参考：[affectUI Project Flow](https://www.affectui.com/illustrations/project-flow)，2026-10-21 实际浏览。参考页将其定义为动画插画；本稿独立制作业务界面，不复制其付费源码。Figma MCP 当前返回 Starter 调用额度耗尽，因此本轮以可点击网页交付，没有修改 Figma 文件。

## 打开

```sh
node research/prototypes/workflow-project-flow/serve.mjs
```

- [A：空间画布](http://127.0.0.1:4331/?variant=A)：左侧运行切换、中央分支画布、右侧节点详情。
- [B：横向工作台](http://127.0.0.1:4331/?variant=B)：顶部运行切换、横向依赖画布、底部节点详情。

底部方向稿工具条可切换两种布局，左右方向键也可切换。状态面板显示完整演示数据。此服务器只监听本机；关闭后可用上方命令重开。

## 可检查的交互

1. A 正文第 4 轮待验收，清单第 2 轮和索引第 1 轮已验收；索引明确采用正文第 3 轮、清单第 2 轮。
2. 勾选正文验收项后通过验收，旧索引仍显示原采用版本；「查看影响与采用新版」只列交付索引。
3. 确认采用，仅索引创建第 2 轮可开展，清单与 B 运行不变；开展后才固定本轮采用的输入。
4. 退回必须填写修改意见；仅选中节点新建轮次，旧稿及意见保留。
5. 方向稿工具条可模拟外部接手、提交，再回到产品界面逐项验收。切换运行保留各自选中节点。

全部状态只保存在内存中，不调用真实 Worket、执行者或数据库，不与上一轮真实任务验收混淆。未实现拖拽编排、画布缩放、自动调度或持久化；稿件按宽工作台展示，窄桌宠窗口如何进入该工作台尚待评审。
