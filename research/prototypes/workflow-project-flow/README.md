## 可检查的交互

1. 「连接关系」查看四条上游成果/材料到下游输入的固定映射；正文与清单互不依赖。
2. 在 A、B 两次运行间切换，保留各自选中节点；两者有独立输入、节点状态和历史。
3. 「待验收」列出所有运行的当前待验收节点，点击精确进入某次运行、某节点、某一轮。
4. 正文第 4 轮逐项验收通过后，索引仍采用正文第 3 轮；「查看影响与采用新版」只列索引。
5. 确认采用只创建索引第 2 轮；开展时固定正文第 4 轮、清单第 2 轮。底部可模拟接手与提交，再逐项验收。
6. 退回必须填写修改意见，仅当前节点创建新轮；旧交付、意见和另一运行保留。正文卡下面的历史条可打开旧轮次。

## 材料与发布边界

用户提供的 README 将重建源码与素材标注为分析材料，并注明不要作为产品发布。本机 `/reference` 请求到达时才从该目录读取 CSS、HTML 和素材，原稿文件与图片未复制到此目录、Git 或 Worket 构建。换一台机器时，可通过 `WORKET_FLOW_REFERENCE_DIR` 指向本机材料目录；材料缺失只影响参考页，不影响业务原型。

Worket 业务原型另写 HTML/CSS/JavaScript，使用仓库已有 WorkBuddy 标志，不导入原稿的人物、品牌贴图、手势图和自动演出动画。参考页按原始 `2312×1644` 整体缩放；业务界面保留可操作字号，按宽工作台重排，不能宣称逐像素还原。外层奶油白与绿色主操作延续现有 Worket。

全部业务状态只在内存中；没有调用 Worket、数据库、真实执行者，没有改变客户端、已验收任务、Figma 或安装包。拖拽编排、画布缩放、保存连接、持久化、长链路和窄窗口适配不在本稿范围；本稿最小工作面为 980px，小窗口横向滚动。
