# 技能执行依赖

2026-09-23。在现有 materialRoles 中增加可选 kind:SKILL；普通资料省略 kind，兼容历史定义。技能是执行依赖，约定中的交付、约束和验收仍由用户的要求决定；技能正文不自动升级为用户约束。

## 提取与确认

客户端声明 skillSchemaVersion:1；服务提供 skillSchemaVersions:[1]。新客户端在发送记录前检查该能力，旧服务明确要求升级。旧请求保持原提示，不接受未声明能力的 SKILL 输出。新协调/增量提示分别为 v2.6/v1.7。

只有明确提到可复用技能才声明技能角色；本次工具、产物路径或历史做法不自动成为依赖。未采纳 Agent 建议继续阻断待审，必需方法沿用原有来源确认规则。模型只提技能名称/用途，不生成本机路径、不安装、不执行。

用户在审阅中可切换“资料文件 / 技能目录”，明确选择含 SKILL.md 的目录。目录选择包含其中全部配套文件；不会扫描其他技能目录，不上传目录正文或路径。切换类型须重新绑定；改变资料角色的增量 REPLACES 也须重新绑定。

## 固定目录与新实例

暂存或直接发布时复制选定目录，保留相对路径与可执行位，记录每个文件的 hash、大小和相对路径；清单 hash 标识目录版本。入口必须为非空 SKILL.md。整个目录至多 512 个文件/子目录，所有固定资料合计不超过 50 MiB；用户选择的入口目录先解析为真实位置，支持安装目录别名；目录内部拒绝符号链接和非普通文件，不追踪其他目录内容。

目录存为本机内容寻址副本，草稿通过 Draft.materials、已发布定义通过 definition_material_refs 持有引用，共用所有权清理。原目录移动或删除不影响已确认版本；新 skill 内容需重新绑定并发布新版本，旧实例仍指向旧定义与副本。新建实例、导出和 MCP 读取均校验全部目录文件及权限位，缺失、增加、修改或损坏均阻断，不依赖旧交接包缓存。

WorkPackage.skills 提供名称、必需性、固定入口/目录、hash 与文件清单。普通 fixedMaterials 不再混入技能；Markdown 工作包单列执行技能。执行者先读入口，按固定目录解析配套文件，最后仍由用户关联本次产物及逐项验收。Worket 本身不运行用户绑定的脚本。

## 范围与后续

本轮保证用户选定目录的版本及完整性。目录外的其他技能、插件、网络服务、运行环境和系统权限仍需执行者核验，不因目录存在而被视为已安装。没有自动递归安装依赖、远端文件传输或跨设备技能同步。HyperFrames 等由多个技能/插件组成的执行环境仍需补充分开的依赖声明与实际执行验收。

合成技能通过 QA 执行证明相对模块及参考文件可用，但不能代替外部目标 Agent 的接手证据或实际视频业务收益。验收见 [技能依赖验收](../acceptance/skill-dependencies.md)。
