# 候选所用聊天来源的变化审阅

2026-09-23，第 20 轮。

提交快照保持不变，后来发生的修订、待复核或缺失不能静默替换当时的原文；同时不能让用户在不知情时把已经变化的依据当成当前要求。

审阅时只对照本次提交选中的聊天事件与本地最新观察。明确展示提交原文及当前修订，区分暂未找到、确认缺失和记录不可用；未同步的外部变化无法判断。新增未选消息不触发复核，已发布基准的历史依据也不触发本次复核。文件仍沿用固定版本及显式更新规范版本流程。

有变化时可修改候选、关闭后重新选范围提炼，或明确确认继续采用当前候选。确认绑定当前变化集合；发布前再次核对，领域事务内拒绝缺失或过期的确认。对照数据只在本机使用，不追加模型输入或改进样本。确认日志保存来源引用、内容 hash、草稿修订及定义 ID，不额外复制原文。重复发布命令保持幂等；已发布定义和旧实例不随来源变化。

验收：旧客户端同场景无提示；新客户端审阅打开期间再次修订使旧确认失效；窄面板可查看原文/现文并确认发布、新输入复用；stdio 全历史读取中的消息缺失可见且阻断未确认发布，恢复后不再标作缺失。领域测试覆盖新增无关消息、过期确认、待复核/缺失/同文恢复、审计原文最小化和旧实例不变。真实模型调用为零；合成模型边界不代表语义或实际业务验收。
