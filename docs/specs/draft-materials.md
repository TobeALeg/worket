# 草稿固定资料暂存

2026-09-23。用户选择的文件和完整技能目录在“暂存”时保存为经过校验的固定副本。关闭、重开及应用重启继续使用该版本；原件之后改变或删除，不会改变已暂存内容。重新选择才替换版本。界面区分“待暂存”和“已固定”。

草稿是固定副本的所有者。发布后所有权交给定义版本；移除角色、取消、来源永久删除使草稿失效时清理不再使用的副本。其他草稿或已发布定义仍引用的副本保留。手动修订入口恢复同一基准版本下尚未发布的手动草稿；新模型提炼任务不混入这个入口。

现有角色、类型、大小、hash、技能目录校验保持。保存失败不改变旧选择；发布仍校验固定内容。未暂存的选择没有持久化承诺。后台协议和模型提示不变，不自动扫描原路径，不执行所选技能。取消清理和普通事务回滚有覆盖，未宣称断电时文件系统与数据库完全原子。

2026-09-23 编辑隔离补充：条目 key 只在所属栏位内唯一。删除方法、输入或其他栏位的同名条目不得清空资料选择；只有删除 materialRoles 中对应角色才清除其待暂存绑定。

2026-09-23 暂存边界补充：撤销只针对本次尚未成功暂存的编辑。成功暂存建立新的固定资料状态并清空旧撤销快照；失败暂存保留编辑、资料选择和撤销。继续编辑或显式更换资料仍可使用新的撤销，不从旧待选路径恢复材料。
