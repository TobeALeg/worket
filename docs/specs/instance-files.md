# 实例文件版本与显式更新

2026-09-23，第 16 轮。目标是使“同一约定 + 新输入”真正相互独立。

创建时固定 FILE 输入及已选择参考案例，副本归属于实例，保存 hash、原路径、实际路径、文件名。导出、复制、MCP 读取均核验副本。任何原文件变化都不自动更新实例。

“本次文件”只允许 OPEN 实例重新选择 FILE 输入、移除参考，或将 legacy 参考按创建时已知 hash 固定。legacy 输入没有历史 hash，必须重新选择，不能推断今天的文件就是历史版本。表单携带输入绑定 hash，陈旧表单拒绝；同 command 重试不重复记录。长期 contract、其他实例、已有手工编辑保持各自来源。

保存追加输入修订、更新当前派生值、清空该实例各绑定读取回执。旧交接包继续使用原副本，当前包读取最新副本。旧版兼容读取也必须发生在最后一次输入修订之后，取消交接/恢复原会话不能恢复已失效读取证明。

失败创建清理实例副本；永久删除只删除当前实例持有目录。单文件限额沿用 MaterialStore，目录输入仍通过 SKILL 专用机制。未实现自动监视原文件、跨机器传输或后台附件上传。

验收优先真实 Electron 的版本选择→两次创建→覆盖原件→删除原件→显式更新→HTTP MCP 重读；另验证损坏、参考修复、命令幂等与删除隔离。合成机制结果不冒充真实用户交付。
