# 改进样本发送边界

2026-09-23。参与改进的停止与目的地限制必须在请求实际发送前仍成立。

ImprovementCollector 在选择队列项时与 WorketAIClient 异步连接完成后各检查一次：采集器未关闭、订阅状态与原目的地未变、当前服务/身份匹配；上传还要求全局开启且授权未过期。stop 清除待发正文，重新开启不复活旧订阅。删除只检查 DELETE_PENDING 和原身份，不要求参与改进继续开启，因此退出后仍能删除既有样本。

uploadSample/deleteSample 通过与提炼相同的 beforeSend 回调把检查放到 request.connect 之后、fetch 之前。等待连接期间撤销不会发送。已经开始 fetch 的请求可能到达服务；停止不是远端撤回，仍需单独删除。收到原服务的有效确认后可清除队列项，不因随后切换配置而将已成功请求伪装失败。

沉淀/复用的改进授权先固定服务身份与本次授权代次；能力查询后及创建本地动作之前再次核验。停止后再开启仍使旧待定授权失效，需重新提交。未请求改进授权的本地流程保持原行为。关闭/停止导致的预发送取消不覆盖停止状态，也不制造同步失败；服务变化仍显示可重试的 SERVICE_CHANGED。

本轮不改变采集内容、保留期限、默认偏好和样本协议；不将已经发送的数据描述成已撤回。参考 [验收](../acceptance/improvement-send-boundary.md)。
