# Worket 工作流上手指南

任务标识：WK-START-1021-A

面向第一次使用 Worket 工作流的个人用户，说明如何把已有 Contract 连成流程、开展两次独立运行并完成第一轮交付。

## 一、准备

工作流入口只能从**已确认 Contract 的固定版本**创建流程。注意这里是 Contract「已确认」，不是「已验收」——「验收」只用于运行中的节点成果，两者不要混用。

连线前想清楚三件事：每步产出什么、下一步拿它当什么输入、哪里可以并行。支持顺序、并行、汇合三种连法。当前没有动态分支、循环、跨设备同步、执行容量队列、操作系统级隔离和无人值守发送，设计时不要依赖这些。

## 二、连接与保存

按类型把指定输出连到指定输入。连接一个实际输入，按下面编号操作：

1. 选择下游节点。
2. 在输入来源区域点击要接的那一个指定输入（例如交付索引的「已验收正文」）。
3. 在「连接 Contract」弹窗的输入来源下拉中，选择上游「撰写指南」节点的 document 输出。
4. 保存这条连接。
5. 最后保存流程版本。

两端必须同为 FILE。清单节点独立读取本次材料，不接正文；只有交付索引才汇合正文和清单。

保存分两种：

- **草稿**：约 500ms 合并保存到 SQLite，可暂不完整；冲突时保留当前输入，也可另存。
- **正式保存流程版本**：保存时才完整校验类型、必填、选项和循环，全通过才算一个可用流程版本。

返回、隐藏或正常退出前，等保存确认回来再走；强制终止或断电仍可能丢掉尚未落库的输入。

## 三、开展两次独立运行

1. 点**「开展一次」**，进入新建运行页。
2. 填写本次运行名称，如「第一轮-客户 A」，便于日后按名称筛选。
3. 为本次运行的各入口输入分别选择内容，选定后即被本次运行固定。
4. 点**「创建并开展」**：生成独立运行 ID、节点工作、轮次、目录和验收记录；文件按内容快照加 SHA-256 固定，原文件后来变了也不静默替换已开展的下游输入。
5. 再点一次**「开展一次」**，开始第二次运行。
6. 填第二个名称（如「第一轮-客户 B」），并选择这一轮各自的输入；两次运行互不更新成果。
7. 点**「创建并开展」**：节点全部前置工作验收通过后才可开展，然后点**「开展工作」**并选执行者。打开外部应用不等于已发送或已执行，必要时要在执行者里确认发送真的发生。
8. 在运行内快速切换两次运行，界面会记住各自选中的节点；用**「所有运行」**按名称、流程、状态筛选和分页；到**「待验收」**逐项验收，它只列当前轮次并显示运行、版本、节点和轮次，暂停项要先恢复。

## 四、提交和验收

执行者可调用 `submit_workflow_outputs` 提交，或由你在界面点**「关联并提交成果」**。固定文件或文本后状态为**待验收**，只有你逐项验收通过才放行下游——文件存在不等于验收通过。固定文件沿用 50 MiB 单文件上限；常见文本在 256 KiB 以内可在应用内预览，其他文件在本机打开。

## 五、三种失败情形的恢复方法

1. **类型不匹配**：正式保存流程版本时被拦下报错。先删掉这条连线，回上游节点确认它的输出类型，再改接到类型一致的输入；或先修正该节点的输出定义，重新连接后再次正式保存。草稿保存不会被拦，但草稿可暂不完整，不能把草稿存下当成校验通过。
2. **上游未验收**：本节点的**「开展工作」**不可用。打开上游节点确认成果已提交并处于待验收，由你逐项验收通过后，回到本节点刷新即可开展。若上游出了新版，已开展的下游仍沿用旧成果，必须先查看影响范围、再明确确认采用新版，才会为后续工作建立新轮次；影响按依赖闭包保守计算，内容相同也不省略重做。
3. **执行者只打开了未发送的任务草稿**：节点有工作，但**「待验收」**里没有它。这里要分清两种草稿：流程编辑草稿是你在流程编辑界面的编辑内容，约 500ms 合并保存、可暂不完整、不经过完整校验，它永远不会成为待验收成果；执行者任务草稿是执行者里还没发出的任务内容，两者不是一回事，不能把流程编辑草稿的自动保存当成执行者已经干活。按下面顺序处理：在执行者界面确认本轮工作 ID 和任务内容与本节点一致，再点击**发送**；等真实执行跑完并生成文件（打开外部应用不等于已发送或已执行，没有真实生成的文件就提交不了）；确认文件已生成后，让执行者调用 `submit_workflow_outputs`，或由你在界面点**「关联并提交成果」**固定文件或文本，状态变为**待验收**；最后到**「待验收」**逐项验收，验收通过才放行下游。

## 六、如何继续

- **退回修改**：必须填写修改意见，会创建新轮次和新 WorkInstance，旧成果与验收历史都保留。**「重做这一步」**同样创建新轮次，旧轮的迟到提交不能覆盖当前轮。
- **暂停**：停止新的准备与交付，不保证能终止已经在外部执行的工作。
- **查找**：异步动作固定目标，迟到结果不拉回旧页面，回到**「所有运行」**或**「待验收」**按当前轮次处理。
