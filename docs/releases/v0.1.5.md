# Worket v0.1.5

## 本次更新

- 工作状态在开始记录、记录变化和交接时自动准备；交接复用最新有效状态，省去独立“整理”步骤。
- 点击“沉淀”直接开始后台处理，沿用已保存的改进偏好；生成后仍审阅候选再保存。附件正文可从三点菜单单独选择。
- 沉淀审阅更紧凑，支持追溯依据、条款变化与局部修订；暂存草稿保留所选材料，组合技能保持目录关系和固定版本。
- 各执行者使用统一交接内容，保留同一工作身份，传递当前阶段、有效要求、成果依据和下一步。
- 精简最近活动与工作详情：历史图标、三点工作菜单、执行者右对齐；全局菜单改为三道横线，服务设置通过返回箭头逐级返回。

## 更新与数据

适用于 macOS Apple Silicon。下载 ZIP 后退出 Worket，将解压得到的 `Worket.app` 替换到“应用程序”，重新打开即可；如接入配置提示变化，重启相应执行者应用。

现有工作记录与设置沿用原数据目录。升级不会自动开启历史工作的后台模型处理；记录与交接的状态准备不额外读取附件正文。后台处理结果仍可能有误，候选定义须由用户审阅确认。

安装包采用 ad-hoc 临时签名，未使用 Apple Developer ID 签名或 Apple 公证。随附 SHA256 文件用于校验下载完整性。
