# Worket v0.1.4

发布日期：2026-09-18。

## 本次更新

- 正式版内置 `https://worket.dandi.site`，首次使用云端能力时自动接入，不再要求普通用户配置模型地址或复制管理员令牌。
- 新增匿名稳定用户身份与独立设备身份。模型额度、请求幂等和明确授权的上传内容按用户归属，单台设备仍可单独撤销。
- 新增恢复码：在另一台设备输入恢复码，可恢复同一匿名用户；恢复码只保存在本机系统安全存储，服务器仅保存哈希。
- “Worket 服务”显示当前用户状态，可复制恢复码或在本机恢复已有用户；手工服务地址与令牌仍保留为高级设置。
- 服务器设置自动迁移到 schema v2；既有手工凭据保留，但不会生成或猜测恢复码。

## 数据边界

用户身份不会让普通模型处理材料自动留存。只有用户明确授权参与改进的记录、沉淀材料或复用反馈进入样本库，继续按授权版本保存 90 天，并支持停止和删除。恢复码相当于匿名账户密码，任何持有者都能恢复该用户，请勿分享。

## 已验证

- 完整自动化测试 125/125 通过。
- 同一恢复码跨设备得到相同用户、不同设备；不同恢复码的上传相互隔离。
- 单设备撤销后该设备失效，另一设备继续可用。
- 服务配置和管理响应不包含安装秘密或恢复码原文。
- macOS arm64 安装包通过签名、解压、Electron 桌面及更新流程检查。
