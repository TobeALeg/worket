# Worket v0.1.11 · 网页聊天导入与插件接入

- 新增 ChatGPT 网页执行者，支持工作包交接及“导入当前聊天”：无需选字，保留当前分支消息的角色、顺序和稳定 ID，先预览再确认保存。
- 增加浏览器插件安装入口、精确 ID 配对、连接检查与修复；HTTP 400 显示具体原因，未准备工作包时提示下一步操作。
- 未安装 Codex、WorkBuddy、ZCode、Antigravity 时跳过历史读取和集成配置；已安装但读取失败仍报告问题。
- 插件 v0.3.1 页面采用与客户端弹层一致的 10px 圆角，保留完整聊天预览与滚动操作。

## 下载与安装

客户端：下载 `Worket-0.1.11-darwin-arm64.zip`，退出 Worket，解压替换“应用程序”中的 Worket.app 后重开；原有记录与设置保留。已有版本可通过“检查更新…”下载。macOS ARM64 安装包采用 ad-hoc 签名，未进行 Apple 公证。

插件：下载 `Worket-browser-extension-0.3.1.zip`，解压到固定目录，在 Chrome / Edge 扩展管理页开启开发者模式并加载插件文件夹，再到 Worket → 应用菜单 → 浏览器插件完成配对。客户端也内置相同插件，可从该入口准备安装目录。

已安装插件的用户：将新版文件覆盖到原加载目录，并在扩展管理页点击“重新加载”；保留原目录可保持扩展 ID。需要时点击 Worket 中的“配对 / 修复连接”。

每个 ZIP 均附 `.sha256` 校验文件。插件不是浏览器商店自动更新；客户端更新不会替代浏览器中的手动重新加载。

## 范围

“导入当前聊天”读取当前分支的消息文字，不包含附件正文或其他分支；生成中、页面切换、历史加载或顺序无法确认、超限时明确失败，不静默截断。此次发布提供 macOS Apple Silicon 客户端和 Chrome / Edge 插件，不包含 Windows 客户端包或公网后台部署。
