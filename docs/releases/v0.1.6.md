# Worket v0.1.6

本版修复代码较多的长记录在沉淀时出现 `INPUT_TOO_LARGE` 的问题，并更新桌宠外观与状态反馈。

- 保留用户和助手对话、规范资料及失败线索；明确的实现代码读写正文在分析输入中省略，完整原始记录仍保存在本机。
- 超长内容按原文位置分块，汇总只携带经过核验的必要引用，避免重复装入全部历史。无法确认用途的内容保守保留；必要内容超过预算时给出明确原因。
- 未确认建议保留独立来源与状态，继续交给用户审阅，不自动合并成已采纳规则。
- 桌宠使用新的拟物外观、贴边姿态及头顶状态灯，展示工作、沉淀和更新下载状态。

原失败记录已通过真实模型与客户端隔离验证：请求从 750,278 字节降至 455,631 字节，7 条用户消息、85 条助手回复逐字保留，成功产生 48 条候选。该结果是单个真实样本的验证，不代表所有记录都有相同比例的体积下降。

macOS Apple Silicon 安装包及 SHA-256 校验文件随 Release 提供。安装前退出 Worket，解压并替换“应用程序”中的 Worket.app，再重新打开；原有记录和设置沿用。

安装包沿用 ad-hoc 签名，未做 Apple 公证。更新提示的原生模态弹窗可能阻塞 Hook 的已知问题仍需后续处理，见此前诊断记录；本版更新相关改动为状态可视化。
