# Worket v0.1.9

汇总 v0.1.8 之后已合入 main 的客户端更新，适用于 macOS Apple Silicon。

- 最近活动整合多执行者聊天来源，支持顶栏搜索，改善来源选择与历史导入体验。
- 改进沉淀审阅：可直接添加约束，已保存契约可编辑生成新版本，减少重复确认。
- 加入工作流组合、定义与运行地图，以及节点交付验收、返工和旧轮次状态清理。
- 交接优先直接交付完整工作说明，长内容沿用 MCP 读取；交接入口采用内联圆形图标、Dock 联动和边缘滑动。
- 修复 WorkBuddy 账号快照缺失时的历史读取与恢复刷新，更新桌宠上下文提示和页面控件。
- 核对交接图标官方来源，统一高清圆形满版，网页版使用灰色细线地球角标。

## 安装与升级

下载 `Worket-0.1.9-darwin-arm64.zip` 和对应 `.sha256` 校验文件，退出 Worket，解压后将 Worket.app 替换到“应用程序”，再重新打开。已有版本也可通过 Worket 菜单“检查更新…”下载。

继续使用原有本地记录和设置。旧版数据库首次打开时会迁移，并按迁移步骤保留备份；旧客户端无法读取新版数据结构，回退应用时需同时恢复匹配的数据备份。

安装包采用 ad-hoc 临时签名，未进行 Apple 公证；macOS 可能要求在“隐私与安全性”中确认可信来源后允许打开。本次只发布 macOS ARM64 客户端，不包含 Windows 安装包或新的后台部署。
