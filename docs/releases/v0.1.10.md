# Worket v0.1.10

固定工作只需填写本次内容，即可在本地直接开始；之后从工作中查看本次执行依据，继续修改或验收。

- 普通 Contract 默认使用 Codex 本地自动执行，无需去 Codex 再点击发送。需要本机已安装并登录 Codex。
- 自动使用同一 Contract 记住的项目文件夹，首次从来源会话继承；无唯一来源时准备默认本地目录，无需手动选择。
- 发起时固定 Contract 版本、本次输入、完整执行说明和项目资料副本。从工作详情的“执行依据 · 继续”查看构建、实际会话、权限与执行记录。
- 支持在原聊天追加修改、处理命令与文件权限请求、停止当前回合。回合结束保留待修改或验收状态，不自动确认交付。
- 新工作直接使用约定和本次输入，避免继承旧工作的进度或等待无关的状态整理。
- 修复可选改进采集在网络失败时阻断本地创建的问题，样本先入本地队列，上传前继续检查授权与接收策略。
- 包含此前已合入主线的活动查看清理、沉淀列表信息与工作流运行概览改进。

## 安装与升级

下载 `Worket-0.1.10-darwin-arm64.zip` 和对应 `.sha256`，退出 Worket，解压并替换“应用程序”中的 Worket.app，再重新打开。已有版本可使用菜单“检查更新…”。继续使用现有本地记录和设置；替换前保留旧应用及数据备份。

本次发布 macOS Apple Silicon 客户端。安装包使用 ad-hoc 临时签名，未进行 Apple 公证；首次打开可能需要在 macOS“隐私与安全性”中确认来源。不包含 Windows 包或后台部署。

自动执行目前限本机 Codex。跨设备同步、云端调度、成果自动登记到工作流和自动验收尚未包含。应用退出会关闭它所拥有的执行连接，未决状态保留为待核对，不会自动重复发起。执行权限以 Codex 实际配置和回执为准。
