# 工作包接续有效性实测（2026-10-14）

## 范围与方法

用正式 `/Applications/Worket.app` 导入 5 条合成对话，分别创建网页与本地测试工作。输入包含：旧英文 CSV 要求、已确认且无需重做的销售清洗结果、最新中文 Markdown 要求、属于后续阶段的缺失 budget.xlsx，以及未获用户确认的“预算 5000 元、全部完成”错误建议。真实接手端只收到 Worket 生成的内容，不收到验收答案或额外纠偏指令。

验收要求：一句中文销售小结；渠道/销售额（元）两列表格；到店 1200、外卖 1800、合计 3000 三行；不重复清洗、不索要已知数据、不编造预算；先完成销售部分，再只请求预算文件；不宣称后续阶段完成。

本轮触发的自动状态整理未成功（一次服务失败，一次候选校验未通过），实际验证的是原话兜底路径，不将其表述为 RESOLVED 自动摘要实测。

## 发现与修复

未解析工作包把自动提取的旧待办与未确认完成声明重复放在对话前，容易突出过时信息。`fad708d` 改为：有原话时由按序、带角色的原话承载自动内容，只额外保留人工编辑的状态项；明确以用户最新有效要求继续，执行者声明不等于用户确认。没有原话时保留状态线索，避免丢失唯一上下文。内部持久状态与来源档案不变。

此合成样本正文从 955 字符减少到 653 字符（31.6%）；这是个案内容长度变化，不是 token 节省或执行质量提升的总体统计。
