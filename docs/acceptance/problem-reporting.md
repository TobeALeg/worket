## 交付

品牌栏唯一图标打开反馈；返回、关闭、Escape 与窗口收起恢复正常操作。文字、所选截图、问题时间、固定日志范围与本次日志选择静默落盘；初始未勾选日志。截图按钮明确写为“收起反馈并截取工作页面”，先恢复工作页面，真实 capturePage 后预览，确认加入草稿仍保持反馈关闭。原工作页面 DOM 保留，重启不恢复反馈展开状态。

提交冻结完整包，经独立身份检查和后台能力声明上传；全部材料一次入库后才返回报告编号与 hash 回执。断网与回执丢失可重试同一报告，身份变化暂停，取消与删除墓碑阻止迟到上传复活。私有后台分别展示用户材料和程序轨迹，处理状态、内部备注与公开说明分开；客户端只显示本人报告及公开内容。

## 上线与当前边界

后台已升级，公网反向代理已支持 25 MiB JSON 请求；本地客户端已启用，公开客户端 Release 尚未发布。继续禁止公网 /admin 和正文日志。活动库的 30 天清理与删除已测试；历史备份删除重放尚无自动任务，上线必须落实 server/README.md 中的恢复规则。

首版不采集原生崩溃转储、堆栈或工作正文；反馈面板完全无法打开时的独立恢复入口仍需另行设计。容量和过期有明确上限，存储失败不会冒充已保存或已收到；诊断文件无法读取时附带不完整标记，仍可提交有效文字与截图。
