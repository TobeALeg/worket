# 问题反馈与诊断日志本地验收

日期：2026-10-08。用户确认风格 A 单页版、每次反馈确认附日志；实现分支 `codex/problem-reporting`。本轮仅为源码与本地应用交付，未升级公网后台、未发布新的 GitHub Release，也未上传真实用户材料。

## 交付

品牌栏唯一图标打开反馈；返回、关闭、Escape 与窗口收起恢复正常操作。文字、所选截图、问题时间、固定日志范围与本次日志选择静默落盘；初始未勾选日志。截图按钮明确写为“收起反馈并截取工作页面”，先恢复工作页面，真实 capturePage 后预览，确认加入草稿仍保持反馈关闭。原工作页面 DOM 保留，重启不恢复反馈展开状态。

提交冻结完整包，经独立身份检查和后台能力声明上传；全部材料一次入库后才返回报告编号与 hash 回执。断网与回执丢失可重试同一报告，身份变化暂停，取消与删除墓碑阻止迟到上传复活。私有后台分别展示用户材料和程序轨迹，处理状态、内部备注与公开说明分开；客户端只显示本人报告及公开内容。

## 自动验证

`npm run build` 与 `npm run build:server` 通过。最终完整回归 299/299 通过（6.5 秒，无跳过），结果位于本地 `output/playwright/problem-feedback/test-results.txt`。收件箱列表在 SQLite 内去除图片字节和事件再返回，避免批量加载完整截图；未知上传的取消墓碑受设备限额约束，已有报告删除始终可用。

新增 8 项有效检查涵盖：白名单字段与图片/授权完整性；错误原文和路径不入日志、同一操作 trace 关联及未正常退出标记；冻结范围、队列与丢失回执后的重启幂等；身份变更暂停、取消墓碑与内容冲突；草稿图片/选择恢复及 7 天过期；后台持久化、容量限制和 30 天清理；无模型配置的真实 HTTP 接收、同主体请求关联、他人报告隔离、私有图片权限、内部备注不外露、删除与撤销；取消墓碑容量限制不阻止已有报告删除。

`npm run package:mac` 通过，生成 `release/Worket-darwin-arm64/Worket.app`（arm64，Electron 44.1.1，产品版本仍为 0.1.8，本地构建）。检查 ASAR 确认反馈页面/CSS、主进程报告与诊断模块、共享契约已入包；项目 server、test、output 和服务数据目录未入包。真实 UI 验收使用未打包 Electron，打包产物本轮进行了构建与文件检查，未宣称已安装或发布。

## 原生桌面与管理员页面

使用临时 WORKPET_DATA_DIR、独立浏览器配置和桥接文件，禁用机器集成安装；测试后台只监听本机 18791，未配置模型，测试服务凭据仅进入隔离存储。

原生 Electron 已执行：打开唯一入口 → 填写文字 → 勾选日志 → 收起反馈截取原窗口 → 预览确认 → 正常工作页面继续可用 → 点图标恢复文字和真实图片 → 提交获得完整接收回执。管理员网页查看真实截图和材料，保存内部备注及公开说明，客户端刷新显示“已解决”及公开说明，未出现内部备注。

## 上线与当前边界

先升级后台，再发布客户端。公网反向代理需支持 25 MiB JSON 请求，继续禁止公网 /admin 和正文日志。活动库的 30 天清理与删除已测试；历史备份删除重放尚无自动任务，上线必须落实 server/README.md 中的恢复规则。

首版不采集原生崩溃转储、堆栈或工作正文；反馈面板完全无法打开时的独立恢复入口仍需另行设计。容量和过期有明确上限，存储失败不会冒充已保存或已收到；诊断文件无法读取时附带不完整标记，仍可提交有效文字与截图。
