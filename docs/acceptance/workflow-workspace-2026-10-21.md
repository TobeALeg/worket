# 工作流操作归属与日常工作台验收

范围：固定操作对象、过期页面请求隔离、流程草稿、跨版本运行列表、运行切换及集中待验收。用户要求本机不写、不运行单元测试，允许既有 CI 照常运行；现有迁移测试仅调整 v5 的夹具清理与版本断言。以下通过真实 Electron、SQLite、固定文件和正常退出重启验证；外部执行者与准备服务使用隔离夹具，不发送真实任务。

## 验证清单

| 用户可见行为 | 交互与证据 |
| --- | --- |
| 未完成流程也能保存，返回后恢复 | 实际输入、添加 Contract、返回、草稿重开、发布校验阻止不完整内容 |
| 正常退出保存最后输入 | 未等 500ms 即正常退出，重启恢复，核对 SQLite 内容 |
| 保存冲突保留本页内容 | 在隔离第二调用中修改同一草稿，原页面保存失败、返回被阻止，另存副本后可继续 |
| 预览期间切节点不串位 | 人为延迟真实预览调用，点击其他节点，再放回结果，原预览不弹回、两节点验收状态不变 |
| 异步开展结束不拉回旧页 | 控制交付响应延迟，切到运行列表后返回响应，仍停留在列表，原节点工作保留 |
| 验收冲突不自动换目标 | 验收框打开期间另一步变化，提交被版本检查拒绝，勾选和意见保留 |
| 重复点击只验收一次 | 对同一真实按钮连续点击，核对 SQLite 验收事件只有一次 |
| 多实例切换记住节点 | A 切节点后转 B 再回 A，选中节点恢复；同一流程多个版本的运行均可见 |
| 集中待验收只含当前轮次 | 从待验收打开明确运行/节点/轮次，处理后列表减少，其他运行不变，旧轮不出现 |
| 筛选与分页 | 名称、流程、状态筛选；超过一页后加载更多；过期查询不覆盖新筛选 |
| 既有闭环回归 | 连接、并行汇合、退回复验、采用新版、另一运行隔离、重启保留历史 |

视觉核对：工作流入口、草稿编辑页、所有运行、待验收和运行切换的实际截图；检查主操作与筛选可见、窄窗口仍能操作、正文不发生横向溢出。

初次开发回归发现重绘后的按钮仍禁用，已在统一动作结束时恢复同一操作的当前按钮；补充代码复核发现服务设置覆盖页返回需要保留草稿会话，已修正并增加实际点击回归。一轮窄窗口脚本误点已隐藏侧栏，改为可见返回入口后重跑。打包下载曾发生连接中断，沿用本机同版本 Electron 44.1.1 缓存完成构建。失败记录保留，不作为通过证据。

边界：以上使用真实应用运行时和持久化，但外部 WorkBuddy 启动/历史、模型准备及部分响应延迟受控。没有向真实执行者发送业务任务，不能据此声称真实多 Agent 并发或业务质量已通过验收。正常退出等待草稿保存，强制终止/断电仍可能丢失未确认输入。
