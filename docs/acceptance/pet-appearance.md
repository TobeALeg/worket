# 拟物桌宠与啾啾状态灯接入

日期：2026-09-24。分支：`codex/pet-appearance-exploration`。

用户要求按已认可的拟物形象更新客户端并运行，使用啾啾发光色替代独立状态圆点。

## 实现

- 原样复制认可的 v2 主体与 v3 眼部图集到 `src/renderer/pet-assets/`，未生成或改写角色像素。SVG 仅叠加清醒眼睛、芽尖着色与局部光效。
- 休息不发光；记录绿、等待橙、携带蓝、沉淀紫、待审阅青白、提醒及失败珊瑚红。携带和提醒仍是预留类型，无新增业务触发。
- 版本更新的中性波纹与工作光色独立，状态来自 `AppUpdates → PetView`。下载仍需用户同意；失败回到有更新，校验并完成下载后才显示已就绪。开发模式不检查更新。
- 自由态主体约 78px；完整裁切框约 80.23 × 76.89，布局与命中区为 80.25 × 77。原生窗口仍为 304 × 271，左右收纳 32 × 68，上下 68 × 32。
- 便利贴默认使用原素材，透明按钮按图集坐标覆盖，悬停展开操作文字。收纳时复制 SVG ID 并重写引用，避免眼部裁切和芽尖遮罩丢失。状态轮询保留相同状态的 DOM。
- 历史 `/exploration` 原版对照冻结为接入前 `e40e05e` 的 HTML / CSS；预览仍不访问生产 IPC。

## 已验证

`npm run build`、`npm run package:mac`、`git diff --check` 通过。更新及桌面几何单元测试 13/13 通过，覆盖下载失败重试、就绪状态保留及边界约束。

`npm run qa:package` 在隔离资料目录启动真实打包程序，验证：

- 八种工作状态 × 自由/收纳两种素材 × 四种更新状态，共 64 组渲染投影的颜色、眼部、波纹及原尺寸；旧圆点为零。
- 原生自由态的八种工作状态与三种更新信号截图；实际素材解码成功。
- 两秒轮询不替换 SVG；待审阅状态观察 4.5 秒后提示停止且不被轮询重播。
- 鼠标悬停展开便利贴，点击独立便利贴及角色本体均可打开面板；Dock 图标、单实例唤回和面板布局正常。

`node scripts/qa-pet-drag.mjs` 在打包程序中通过真实指针事件与 placement IPC 验证：自由拖动不误开面板、四向收纳、拖出、重启恢复、断屏回收、Dock 中央避让及收纳中途打断。六次收纳采样存在中间缩小帧；睁眼与绿色啾啾的克隆中，无失效 SVG 引用或重复 ID。收纳窗口尺寸与原版一致。

截图已人工查看：自由态各光色、更新波纹和四向贴边，无角色/啾啾被原生窗口裁切。原生截图及报告保存在本机 `output/pet-appearance/native/`、`output/pet-docking/` 与 `output/playwright/`，不提交到 Git。受控状态只用于隔离验收，不代表创建了真实沉淀任务或下载了新版。

随后正常退出 `/Applications/Worket.app`，以原有用户资料启动本分支的 `release/Worket-darwin-arm64/Worket.app --dev`。Computer Use 的实际窗口 URL 和进程路径均确认来自新包；用户原位置恢复为底部贴边，真实记录状态显示绿色啾啾。运行截图为本机 `output/pet-appearance/running-native.png`。
