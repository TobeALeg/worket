## 问题与修复

get_work_context 原先优先返回最后一次保存的交接包。后续状态或产物变化不会进入该包，固定资料已经缺失也可能因缓存而绕过检查。改为每次调用 createHandoffPackage，沿用统一的有效规则、固定版本与资料校验，成功后再记录读取证据。历史交接包不改写。

每次成功读取会保存一个新快照，目前未做相同内容快照去重；这是可观测的存储代价。ArtifactRef 展示本机已记录的最新引用，通用产物路径的磁盘可用性仍由原有主动刷新/交接检查负责；本次重新校验范围是工作包固定资料和本次 FILE 输入。
