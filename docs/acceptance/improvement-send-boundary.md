## 失败与修复

真实本地 HTTP 复现：调用 flush 后暂缓连接，停止参与，再恢复连接。修复前状态 STOPPED 但仍收到一个 283 字节 POST；同脚本修复后收到零请求。内容仅为合成标题，不涉及用户数据。

相同 Electron 验收分别运行：旧 9fd7124 解压客户端 2026-09-22T21-34-37-270Z 失败，界面已经显示停止而服务器收到 POST；新版源码 21-34-05-144Z 通过。实际设置界面取消参与，真实生产 outbox 和 HTTP 客户端处理队列；仅合成登记样本及连接延迟受控，不替换发送结果或服务端存储。

两台隔离托管 HTTP 后台验证：停止前等待的请求不会发出；切换服务保持队列，返回原服务后上传；两边具有同名样本时，待删除请求不转到新服务；全局退出后仍可回原服务完成删除。最终请求计数第一服务 POST/DELETE，第二服务仅用于预置对照的 POST，零模型调用。截图核对状态为“已停止、0 条待同步”。
