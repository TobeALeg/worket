# 工作流关系画布方向（待评审）

日期：2026-10-21。用户指定 [affectUI Project Flow](https://www.affectui.com/illustrations/project-flow) 作为工作流视觉参考。本轮只制作方向稿，未更改客户端界面、领域模型或基础组件库。

## 要借鉴的视觉

以浅色轻卡片、细连线、柔和边界和空间留白表达工作关系。外层保留 Worket 奶油白与绿色主操作，画布试用冷白、浅蓝连接线，节点只呈现名称、Contract 版本、当前状态、执行者、轮次和交付物；长内容进入详情区域。

参考页是面向展示的动画插画，官方同时明确其不适合作为交互产品组件直接使用。这里借鉴视觉语言，将其映射到 Worket 的真实业务对象；没有导入付费组件或把固定插画缩小成操作界面。

## 业务对象映射

| 画布元素 | Worket 含义 | 必须保留的事实 |
| --- | --- | --- |
| 入口资料条 | 本次运行固定输入 | 文件身份和本次固定，不随源文件静默替换 |
| 工作卡片 | 节点使用的 Contract 固定版本及当前轮工作 | Contract 版本与工作轮次分别呈现 |
| 交付物条 | 这一轮的输出 | 可开展、等待接手、执行中、待验收、已验收分别表达 |
| 连线 | 上游输出到下游输入的采用关系 | 右侧或底部详情保留具体来源及采用轮次 |
| 运行切换 | 同一流程的不同运行 | 每次运行有独立节点状态，切回后保留选中节点 |
| 验收与影响确认 | 当前工作复核及显式采用新版 | 新版通过验收不自动替换已开展的下游输入 |

动效的后续设计原则：只跟随真实连接保存、执行回执和业务状态变化，保留减少动态效果偏好；不采用参考插画自动循环演出的进度表达。新动效仍需单独评审。

## 两种布局

**A 空间画布**：左侧切运行、中央显示分支与汇合、右侧查看和处理节点。更接近参考中的纵向展开，适合在工作关系与详细验收之间反复切换。

**B 横向工作台**：运行切换移到顶部，关系从左向右展开，详情在底部横向组织。提供更大的横向工作面，但较长详情需要重新平衡高度。
