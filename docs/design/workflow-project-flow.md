## 业务对象映射

| 元素 | Worket 含义 | 必须保留的事实 |
| --- | --- | --- |
| 顶部运行条 | 整套流程的一次独立运行 | 切换运行不复用其状态、资料或选中节点 |
| 本次材料卡 | 本次固定输入 | 身份和快照固定，不随源文件静默替换 |
| Contract 卡 | 固定 Contract 版本及当前轮工作 | Contract v1 与工作第 4 轮分别呈现 |
| 成果徽标与历史层叠 | 本轮交付及旧轮次 | 待验收、已验收和历史分别表达；历史可查看 |
| 四条依赖线 | 材料/上游成果到下游输入的映射 | 正文与清单并行；索引采用两者明确的已验收轮次 |
| 连接与采用详情 | 来源端口及实际采用版本 | 新版验收不静默替换已开展的下游输入 |
| 待验收列表 | 跨运行的人工作业入口 | 每条定位运行、节点与轮次 |
| 新版影响确认 | 显式选用新成果 | 只为索引建立新轮，保留清单与另一运行 |

## 两种操作布局

**A 关系画布**：顶部运行切换，取消常驻左右栏。材料居中，左侧正文带历史层叠，右侧清单与下方索引形成汇合。点击节点打开浮动详情；更接近参考的空间留白，但详情会暂时遮住部分画布。

**B 验收工作台**：左侧运行列表、中央更紧凑的分支汇合、右侧常驻详情。适合连续验收，但画布空间较小。两种布局共用演示状态，切换时可以直接比较信息组织。

[打开原型、截图与检查记录](../../research/prototypes/workflow-project-flow/README.md)。界面至少需要 980px 工作面，小窗口横向滚动；原型不证明窄桌宠面板可用。宽工作台入口、长链路、拖拽连接与缩放、键盘图导航及完整边界状态仍待正式设计。

## 原稿与交付边界

用户提供的 README 将提取的 CSS、HTML 和图像列为分析材料，并注明不要作为产品发布。原型的本机参考页只在运行时读取用户目录，支持原稿浅色、深色和重播；未将这些原稿或图像复制进 Git、客户端或分发包。此轮业务界面另写，使用仓库已有品牌素材，没有引入原稿人物或手势资产。

本轮没有修改 Figma 节点，不更新页面迁移节点索引；工作流继续排除在现有 49 张页面规范之外。业务状态为内存演示，不调用 Worket 后端、数据库或执行者。原型与说明保留在 Draft PR #49，不作为已认可的产品布局合入 main。
