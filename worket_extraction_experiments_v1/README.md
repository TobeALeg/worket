# Worket 抽取质量实验包 v1.0

这是设计和可编辑模板，不是已完成实验，不包含生产评测runner。

阅读顺序：

1. `01_实验设计.md`：目标、价值边界、数据、六组实验、晋级与停止规则。
2. `02_评分与人工验收.md`：严格覆盖、有用精确率、噪音、人工劳动及评分器反作弊。
3. `03_CODEX_执行任务.md`：交给Codex建立runner和执行对照的工作说明。
4. `04_实验配置模板.json`：默认禁止live调用，所有实验标NOT_IMPLEMENTED。
5. `05_合成边界用例.jsonl`：12个合成测试规格，不是真实用户样本或通过结果。
6. `06_Gold标注示例.json`：带原文证据的合成标注示例，尚无人类批准。
7. `build_templates.py`：生成并检查本包JSON模板的辅助脚本；不是抽取器或评测runner。

本次仅进行了JSON解析、case ID/检查点、示例引用与原文摘录匹配、禁止live默认配置的结构检查。没有调用任何真实抽取模型，没有准确率、收益或人工用时测量，没有修改GitHub仓库或用户真实数据。

真实案例、接收模型服务与费用须获得明确授权；gold与封存材料不得出现在被测模型输入。文件中所有目标数字均为建议决策线，不是结果或行业标准。
